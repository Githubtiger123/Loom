# Pipeline 前端

独立页面替代原先通用资源页，统一调用 Loom API，不直接连接 KFP、Kubernetes 或对象存储。

## 已接入源码

- `/workspaces/:groupId/pipelines`：定义与运行列表，mine/all 权限范围、游标分页；可显式包含已归档定义／已删除运行查看历史。
- `pipelines/new`：创建定义；`pipelines/:pipelineId`：版本及运行记录。
- `pipelines/:pipelineId/versions/new`：上传／粘贴 SDK 编译的单文档 IR YAML（512 KiB 上限），固定父定义 revision。
- `pipelines/:pipelineId/versions/:versionId`：参数 schema、包摘要、原生兼容性与 IR。
- `pipelines/:pipelineId/versions/:versionId/edit`：替换版本 IR，固定版本 revision 与父定义 parentRevision，保存为新修订；不修改已有运行快照，版本名保持不变。
- 定义详情的“归档定义”：确认后调用已有 DELETE 接口；需要先清理全部未删除运行，保留版本／修订历史，不删除存储文件，不提供自动恢复入口。
- `pipelines/:pipelineId/run`：选择版本，固定版本修订，参数类型校验，默认值／显式空字符串／凭据引用分开处理。默认原生 Argo，也可显式选择已配置的外部 KFP。
- `pipeline-runs/:runId`：快照、观测状态、异步操作、停止／删除清理／启动确认。
- `pipeline-runs/:runId/edit`：选择版本修订、修改参数，固定运行 revision；名称与引擎不变。提交只请求停止、清理旧实例并应用配置，等待完成后再在详情确认启动；不会自动重跑或切换到版本最新修订。凭据引用须重新填写。
- 运行诊断：引擎版本、Workflow 名称与 UID、冻结计划摘要、观测／同步／终态归档时间及原因、任务 Pod 身份；提交失败可查看关联操作单。新增数据只来自现有 runtime 接口的白名单字段，不返回冻结规格、存储会话或凭据。
- DAG：按层级展示定义依赖；边界端口用依赖列表补充；实际循环／重试实例单独列出，不按显示名猜测实例映射。节点可查看输入输出、缓存来源及执行策略。
- 节点策略用条件／触发、循环来源与并行度、重试退避、缓存四组说明展示，原始 JSON 保留在折叠区；仅解释固定 IR，不提供在线修改策略。实例支持状态、定义类型／能力、缓存证据、重试历史、迭代索引及名称／Pod 筛选；类型筛选不猜测未解析的映射。
- 指标：数值卡片；后端若提供兼容分类产物则显示 ROC、混淆矩阵。原生编译器当前并不支持产生全部旧 KFP 可视化类型。
- 产物：鉴权下载、按需预览；目录作为归档下载。HTML 使用无脚本、无同源权限的隔离 iframe 和资源 CSP；Markdown 显示源码；不访问产物中的外部 URL。
- 官方原生执行产物可打开“浏览文件目录”：只读目录树、路径导航、全目录文件路径搜索、逐文件预览／下载；单文件产物也支持该入口。文件列表上限 4096、路径最多 64 层，预览 2 MiB、下载 32 MiB；空目录不凭空生成。旧 tar 归档与外部 KFP 不使用新浏览接口，仍保留原预览／下载。
- 在线日志：可见面板内读取 500 行／256 KiB 快照，可每 5 秒刷新，可读 previous；不是 follow 流。
- 归档日志：按执行历史、文件 ID、ETag 和字节偏移分块读取（256 KiB），无需存活 Pod；保留完整性未知与尚未归档状态。
- 历史重试 Pod 可直接跳转归档；URL 仅携带执行实例、任务 ID 与 Pod UID，必须从后端清单精确匹配，未找到时不自动显示其他 Pod。可手动取消定位查看同实例全部归档。`previous` 仍仅指同一 Pod 的上次容器日志。

## 边界与验证

本次只修改源码及格式，不运行测试、类型检查、编译或开发服务器，未做浏览器和真实集群联调；不能将此描述为已验证可运行。

不包含可视化拖拽编排、Python 在线编辑／编译、定时运行、跨运行指标比较或完整 KFP 前端复刻。诊断不包含实时 Kubernetes 调度／镜像拉取事件，缺失记录不能推测为执行成功或失败；任务错误仍结合 DAG／日志与操作单查看。

原生执行、缓存、日志归档和产物存储仍需后台配置。兼容性返回 runnable 仅说明配置及编译检查通过，不是实际运行验证。

文件浏览通过 `/pipeline-runs/:runId/artifacts/:artifactId/files` 及其 `/preview`、`/download` 子接口；内容读取附带列表返回的相对 `path`、`manifestDigest`、`etag` 与 `instanceId`，不接受对象存储 URL／Bucket／Key。文件变化返回 409；读取失败隐藏旧内容，刷新清单后重新选择。没有新增表或迁移，不支持上传、编辑、删除、解包任意 ZIP 或执行模型文件。

写操作不自动重试；相同端点与载荷在不确定失败后沿用幂等键。202 后查看操作与实际观测。敏感查询在可见面板挂载，键包括空间、运行实例及修订；撤权或刷新失败不展示缓存内容。
